# Max Marine Group - Official Website

A comprehensive maritime services website showcasing Max Marine Group's expertise in vessel operations, ship management, marine services, and QHSE standards.

## Project Info

**Repository**: https://github.com/mohamedeltabei1/Max-Marine-Final-Website.git

**Live Site**: [Coming Soon]

## Features

- 🚢 **Services Showcase** - Comprehensive maritime services including vessel operations, ship management, and marine consultancy
- 🏢 **Company Portfolio** - Detailed information about Max Marine Group companies
- ⚓ **Fleet Management** - Overview of vessels and maritime assets
- 📍 **Ports & Offices** - Global presence and facility locations
- 📊 **Case Studies** - Real-world project showcases and success stories
- 🛡️ **QHSE Standards** - Quality, Health, Safety, and Environmental compliance information
- 📱 **Responsive Design** - Optimized for all devices with modern UI/UX
- 🌐 **Multi-page Navigation** - Smooth routing with React Router

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn package manager

### Installation

```sh
# Clone the repository
git clone https://github.com/mohamedeltabei1/Max-Marine-Final-Website.git

# Navigate to project directory
cd Max-Marine-Final-Website

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be available at `http://localhost:8080`

## Tech Stack

This project is built with modern web technologies:

- **React 19** - Latest React with TypeScript
- **Vite 5.4** - Fast build tool and dev server
- **Tailwind CSS 3.4** - Utility-first CSS framework with custom maritime theme
- **shadcn/ui** - High-quality React component library built on Radix UI
- **React Router 7** - Client-side routing
- **TanStack Query 5** - Powerful data fetching and caching
- **Lucide React** - Beautiful icon library
- **TypeScript** - Type-safe development
